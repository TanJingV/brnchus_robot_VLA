02 / PROJECT OVERVIEW

连接模型、控制与观察。

本项目面向双段腱驱连续体支气管镜的建模与控制研究。在 MuJoCo 中构建主动段、被动导管与肺部环境，提供近端及远端弯曲控制、插入控制、tip 相机视角和中心线路径导航模块。工作台支持真实环境与仿真环境入口，并记录多路画面、探头数据及机器人关键点位姿，供控制调试和后续数据分析使用。

罗盘与手柄输入、插入轴控制、中心线路径以及虚拟相机，支持闭环控制研究。

03 / MODELING

两段主动骨架，六根驱动腱。

以项目参数化模型为依据，展示末端结构与离散化方法。

W1–W3 终止于段间连接；W4–W6 贯穿两段。模型保留连续走线带来的段间耦合，控制器通过腱长指令驱动弯曲。

# TDCR Vision Studio 架构

## 产品工作流

界面只暴露一条主任务路径：

```text
数据选择
  → 首帧点击 K0–K6
  → CoTracker3 整段七点轨迹
  → SAM2 黑色主体审核
  → D435 Depth / IR 三维测量
  → 两段连续体曲线约束
  → 结果检查与导出
```

YOLO Pose 不参与默认任务。它只是一种将来可替代“首帧点击”的自动初始化器，
不能与 CoTracker3 同时争夺 K0–K6 身份。

电机/PCC先验、EM端距和旧视频Depth→RGB近似配准放在设置页。电机和EM
默认关闭，避免在检查纯视觉性能时把模型预测混入视觉测量。

## 代码分层

```text
ui.py                         兼容启动入口
workstation/
  state.py                    唯一UI业务状态
  worker.py                   后台任务边界
  widgets.py                  无业务依赖的显示控件
  pages.py                    数据/初始化/重建/结果/设置页面
  window.py                   页面导航与状态转换
  theme.py                    产品视觉令牌和样式

cotracker3_tracker.py         预训练七点轨迹与颜色局部审核
pipeline.py                   单帧3D融合主链路
processor.py                  session级离线任务编排
measurement.py               Depth/IR不确定性融合
curve_model.py               两段连续体几何约束
io.py                         CSV/NPZ/视频输出
```

依赖方向始终是：

```text
UI → processor → pipeline → measurement / curve / IO
```

底层算法不会反向访问Qt控件；页面不会直接修改检测器内部变量。

## 状态规则

- 未选择有效RGB+Depth会话：禁止进入重建任务。
- 未完成K0–K6七点初始化：禁止开始CoTracker3。
- CoTracker3轨迹生成完成后，才逐帧执行三维融合。
- 跟踪点未通过可见性、SAM主体或色带外观审核时，记为无效。
- 几何/动力学补全点必须保留`predicted`标记，不计作视觉实测。
- 每次任务写入独立时间戳目录，不覆盖原始采集数据。

## 透明肺模型中的材料点跟踪

首帧点击只负责确定K0–K6身份。运行时采用非对称融合，避免透明肺壁和固定
套管的强反光把点锁在原位：

1. CoTracker3只提供弱候选位置。
2. SAM2.1视频记忆传播已锁定的黑色连续体实体。
3. 用主体掩膜的帧间运动传播上一帧材料点。
4. 在移动后的局部区域用Lab色带外观重新定位。
5. 用K0–K6顺序和初始化相邻间距拒绝肺壁反光导致的换点。

SAM2只在关键帧执行，关键帧之间使用金字塔光流传播已确认掩膜。固定相机的
前景差分只能作为弱平移后备，不能单独决定每个关键点的中心线位置。

## 追踪与记录状态

`开始追踪 / 停止追踪`只控制计算线程；`开始记录 / 停止记录并保存`控制独立的
线程安全记录门。停止记录会在下一帧边界安全关闭CSV、NPZ和叠加视频，追踪与
预览继续运行；再次开始记录会创建新的编号片段。停止追踪时会安全关闭仍在记录
的片段。

## 页面职责

1. **数据**：会话选择、数据通道和质量检查。
2. **初始化**：视频浏览、一次性K0–K6点击。
3. **重建**：固定主链路、阶段进度、停止和完成状态。
4. **结果**：三维曲线、七点坐标、叠加图和深度图。
5. **设置**：可选先验、旧深度配准和输出策略。

页面之间只通过`WorkstationState`和窗口控制器传递状态。

# 七标志点三维坐标离线处理工作站

## 严格的主体优先识别逻辑

当前版本不再先找彩色亮点，也不会按等间距把驱动机构或肺模型反光补成关键点。处理真实图像前必须先在一帧清晰 RGB 中紧贴黑色末端及 7 条色带拖框并点击“锁定末端并开始跟踪”。这个框只用于建立一次目标身份，后续不会逐帧重新猜目标。每一帧依次通过以下步骤：

1. 局部黑帽和形态连续性只生成粗中心线，不再直接充当最终主体分割结果。
2. 使用 Meta 官方 `SAM2.1 Hiera-Tiny` 的 `Sam2VideoModel` CUDA 流式会话，将首次框选登记为固定 `object_id=1`，用视频记忆在后续帧持续传播同一个实例。
3. 使用稀疏光流仿射预测、帧间 IoU、面积比例、连通域、提示点覆盖率、管径和几何走廊共同审核网络输出，防止掩膜跳到透明肺模型、金属夹具或黑色导轨。
4. SAM2.1 掩膜通过审核后，中心线吸附到神经掩膜中轴；随后才在主体横截面范围内重新检测七条色带。
5. 用弧长顺序和相邻间距把七条色带固定编号为 `K0`（近端）至 `K6`（远端），在原始分辨率上重算亚像素中心。
6. 七条色带整体置信度通过后，才在各自色带支持区域读取对齐深度或左右 IR 三角化结果，得到七个三维坐标。
7. 绿色动态框由 K0–K6 的光流预测驱动，主动段插入时会随七色带区域移动；初始蓝色框在锁定后自动隐藏，避免把条件框误认为跟踪框。
8. 色带被反光短暂遮挡时继续显示 `PRED` 二维预测点，但不把它们冒充 RGB/Depth 三维实测；色带重新可见后自动回到 `VISION`。主体身份真正失锁时停止输出并要求重新框选，绝不切换到另一个黑色物体。

模型权重保存在项目内的 `Visual_information/models/sam2.1-hiera-tiny`，运行时只使用本地文件，不联网。界面标题同时显示 `SAM2.1-CUDA BODY` 置信度、`bands N/7` 和 `3D measured N/7`。

本模块从已采集的 D435、运动控制器和 NDI 数据中估计连续体主动段 `KP0–KP6` 的三维坐标。七点对应主动段弧长：

`[0, 7, 14, 21, 28, 35, 42] mm`

第 0、3、6 点分别对应主动段基座、两主动段连接面和末端。

## 启动图形界面

双击项目根目录中的 `run_seven_marker_offline_ui.bat`，或在 Bronchoscope 环境中运行：

```powershell
D:\anaconda3\envs\Bronchoscope\python.exe -m Visual_information.seven_marker_3d_fusion.ui
```

界面将自动扫描常用的 `d435_sessions` 目录，也可以点击“选择会话目录”打开任意一次采集结果。

## 界面功能

- 会话浏览：显示数据质量等级、帧数、帧率和 RGB/Depth/点云/内窥镜/电机/EM 文件是否存在。
- 同步回放：统一时间轴、播放速度、逐帧查看和拖动定位。
- 多视图：RGB 检测叠加、深度视频、已记录点云、内窥镜画面和七点三维曲线。
- 目标锁定：在清晰条件帧紧贴 7 色带末端拖框并点击锁定；绿色框表示已登记目标，红色框和 `TARGET LOST` 表示必须重新框选。
- 深度标定：调整旧视频的深度范围、Depth→RGB 平移/缩放和近似内参。
- 融合设置：调整形状约束、时间平滑和是否使用电机绳长模型补全遮挡点。
- 数据检查：逐点显示相机坐标、置信度、实测/预测状态和数据来源，同时查看电机与 EM 遥测。
- 批量处理：选择起止帧，生成 CSV、NPZ、检查视频和质量摘要；可以安全停止。
- RGB中心线邻域深度精修：管体中心没有深度时，从边缘提取稳健深度并与电机先验融合。
- 连续形状建模：由七个材料点和局部切向拟合六段精确7 mm材料弧，在两段连接面保持局部连续。
- 管状三维重建：3D窗口显示直径3.5 mm的管体、实测点、预测点、曲线长度和曲率。
- 离线无相位精修：同时利用当前帧前后的数据降低抖动，不引入单向低通的时间延迟。
- EM双探子约束：不直接混用未标定的NDI坐标与相机坐标，只使用两探子端距和相对转角这两个坐标系不变量。
- 跨会话外参：用标志完整可见的参考会话学习电机/PCC局部坐标到D435坐标的刚体变换，供肺内遮挡会话复用。

## 算法流程

每帧按以下顺序处理：

1. 在 RGB 中分割黑色连续体主体，提取其中心线，限制彩色环带的搜索区域。
2. 联合 HSV、Lab、中心线顺序、7 mm 等弧长先验和前一帧状态识别七个环带。
3. 对原始 Z16/对齐深度使用局部中位数、MAD 离群剔除和前景聚类，而不是读取单像素。
4. 数据包含左右 IR 时，沿极线做亚像素匹配并独立三角化。
5. 对 RGB-depth 与 IR-stereo 使用协方差交叉融合，避免把同源观测误当成独立传感器而高估精度。
6. 使用不可伸长长度约束、分段曲率平滑、鲁棒损失和短时运动预测抑制误检与抖动。
7. 旧会话深度有孔洞时，可将六根绳长转换为两段 PCC 曲线。由至少三个视觉实测点估计模型到相机的刚体变换，只补全缺失点。
8. 对预测点沿RGB中心线搜索深度邻域，以电机预测深度作为门限排除肺壁和背景，再拟合平滑的轴向深度曲线。
9. 批处理完成后进行全序列加权二阶差分优化；视觉实测点权重最高，邻域深度次之，电机/PCC预测最低。
10. 每帧使用切向引导的7 mm材料弧重建连续中心线，并用平行移动标架生成管状网格，避免七点折线造成尖角或总长度失真。
11. 会话含两路EM时，默认读取Port 10/11的端距作为软约束；只有确认探子分别固定在主动段近端和远端时才应保持该开关开启。

电机补点始终标为 `motor_pcc_prior` 和 `predicted=1`；它不会被记为视觉实测点。

## 已采集数据的质量等级

### A 级：原始 RealSense BAG

包含原始 RGB、Z16 Depth、左右 IR、时间戳和标定信息，可完整重算并获得最高可信度。

### B 级：`keypoints.npz`

可以重新做时间、形状和多传感器坐标融合，但不能重新运行图像分割。

### C 级：旧版 MP4 会话

现有旧会话通常包含 `rgb.mp4`、`depth.mp4`、`pointcloud_3d.mp4`、`camera_axes.csv`、`motor_axes_100hz.csv`，部分还含 EM 和内窥镜视频。程序会：

- 从 TURBO 伪彩深度近似反解米制深度；
- 用可调参数近似执行 Depth→RGB 配准；
- 同步读取电机和 EM；
- 在视觉深度缺失处使用电机/PCC 先验补全。

由于 `depth.mp4` 已经过伪彩色映射和有损压缩，无法恢复原始 Z16 精度。旧数据输出会明确标记 `metric_quality=approximate`，不能用于宣称毫米级相机测量精度。

## 输出文件

批量处理结果保存在 `Visual_information/outputs` 下：

- `seven_marker_3d.csv`：逐帧七点坐标、置信度、标准差、实测/预测标志和来源。
- `seven_marker_3d.npz`：便于 NumPy、参数辨识和绘图使用的完整矩阵。
- `seven_marker_refined.csv`：利用完整时间序列精修后的七点坐标和每帧形状指标。
- `seven_marker_overlay.mp4`：主体分割、关键点编号和三维结果检查视频。
- `summary.json`：帧数、视觉实测点统计、处理耗时、质量等级和参数快照。

CSV 中的 `kpN_valid` 代表视觉/深度实测有效，`kpN_predicted` 代表该点由时间或电机模型补全。分析时应分别统计两类点。

`seven_marker_3d.npz` 还包含：

- `offline_refined_camera_m`：无相位时序精修后的七点坐标，形状为 `(N, 7, 3)`。
- `curve_centerline_camera_m`：连续体稠密中心线，默认形状为 `(N, 85, 3)`。
- `curve_tangent`、`curve_curvature_1_m`、`curve_arclength_m`：切向、曲率和累计弧长。
- `curve_total_length_m`、`curve_maximum_curvature_1_m`：逐帧形状质量指标。

旧MP4数据中的“邻域深度＋电机”点仍属于融合预测，不会升级为相机直接实测。只有原始深度真正落在标志点支持域内时，`kpN_valid` 才为1。

## 先标定、再处理肺内遮挡会话

1. 选择一个相机和机器人底座位置与正式实验相同、七个环带清楚可见的参考会话。
2. 设置正确ROI，勾选“本次批处理更新跨会话标定”，处理至少30帧。
3. 程序使用每帧至少3个直接三维点进行鲁棒Kabsch拟合，保存到 `seven_marker_calibration/motor_camera_alignment.json`。
4. 打开肺内会话，保持“遮挡会话复用电机→相机标定”开启。视觉不可见的点由已标定PCC模型生成，局部可见点和EM端距继续做修正。
5. 标定残差超过3 mm时，应重新检查ROI、Depth→RGB配准和相机/机器人是否移动；不要用低质量标定覆盖原文件。

EM默认使用Port 10/11，并为两探子相对K0/K6的内缩安装量提供2 mm总偏置。应在机器人拉直时用
`42 mm - 两探子直线距离`重新测量该参数。若两个探子并不对应主动段两端，必须关闭EM端距约束。

## 命令行模式

```powershell
# 实时 D435
python -m Visual_information.seven_marker_3d_fusion --live

# 合成数据自检
python -m Visual_information.seven_marker_3d_fusion --synthetic --max-frames 120

# 原始 BAG（真实图像必须给出首帧目标框；更推荐直接使用 UI 框选）
python -m Visual_information.seven_marker_3d_fusion --bag D:\data\session\realsense.bag --target-roi 0.54 0.41 0.72 0.56 --headless

# 已保存关键点
python -m Visual_information.seven_marker_3d_fusion --npz D:\data\session\keypoints.npz
```

通用算法参数位于 `fusion_config.json`。实际实验应先在界面清晰帧中紧贴目标拖框并锁定；不要通过无限放宽颜色阈值或大范围孔洞填充来掩盖错误匹配。
